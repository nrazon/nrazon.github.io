Como resolver os quebra-cabeças de lógica Coroa, Gêmeos e Caminho

Por Nesim Razon, desenvolvedor Android independente

O Logiclings tem três tipos de quebra-cabeças de lógica e cada quebra-cabeça tem exatamente uma solução, então você nunca precisa chutar. Cada um premia uma forma diferente de pensar. Aqui estão as regras e as primeiras técnicas para experimentar.

Coroa

Coloque exatamente uma coroa em cada linha, cada coluna e cada região colorida, e nunca deixe duas coroas se tocarem, nem na diagonal.

  • Comece pela menor região colorida: é a que tem menos lugares para a coroa.
  • Quando uma região fica limitada a uma única linha ou coluna, nenhuma outra região pode pôr a coroa nessa linha ou coluna.
  • Cada coroa elimina as vizinhas, inclusive as diagonais. Risque essas casas.
  • Quando uma casa é a única opção que resta para uma linha, coluna ou região, a coroa vai ali.

Gêmeos

Preencha a grade com rostos azuis e laranjas. Cada linha e coluna deve ter o mesmo número de cada cor, não pode haver três rostos iguais seguidos e os sinais = e × entre vizinhos dizem se os dois rostos são iguais (=) ou diferentes (×).

  • Se dois vizinhos são iguais, o rosto ao lado deve ser da outra cor, assim nunca há três seguidos.
  • Conte cada linha e coluna: quando uma cor chega à metade, todas as casas restantes são da outra cor.
  • Use os sinais = e × como informação de graça e espalhe pela linha.

Caminho

Comece no número 1, passe pelos números em ordem e preencha todas as casas com uma linha sem cortes.

  • Cantos e casas com apenas um vizinho livre são becos sem saída: o caminho só pode entrar ou sair de uma forma, então a linha é forçada ali.
  • Pense onde está o maior número: o caminho deve terminar ali depois de cobrir tudo.
  • Se uma jogada deixar uma casa que você nunca vai alcançar, desfaça. Os números devem ser alcançados na ordem certa.

Dicas que explicam

Se travar, uma dica do Logiclings não preenche só uma casa. Ela explica a lógica passo a passo e destaca a casa, então cada dica também é uma pequena lição.

Perguntas frequentes

Eu preciso chutar alguma vez?

Não. Cada quebra-cabeça tem exatamente uma solução que se encontra só com lógica.

Os quebra-cabeças ficam mais difíceis?

Sim. Os tamanhos vão de grades 4x4 até 10x10, do fácil ao difícil.

Existe limite de tempo?

Não. Não há pressão de tempo nem vidas. Seus melhores tempos são registrados por diversão.
