6x6 Sudoku: Rules and Solving Tips for Beginners

By Nesim Razon, independent mobile developer

A 6x6 sudoku is the small, friendly cousin of the classic puzzle. You fill the grid with the numbers 1 to 6 so that no number repeats in any row, column or box. It takes minutes instead of an hour, which makes it a good way to learn how sudoku logic works.

The rules

  • Every row contains the numbers 1 to 6 exactly once.
  • Every column contains the numbers 1 to 6 exactly once.
  • The grid is split into six boxes, each two rows high and three columns wide. Every box also contains 1 to 6 exactly once.
  • Some numbers are already given. Pick an empty cell, then tap a number to place it.

Your first techniques

  • Look for the last missing number. If a row, column or box has five numbers, the sixth is obvious.
  • Cross-check. For an empty cell, list the numbers already in its row, column and box. If only one number is left, it goes there.
  • Scan for a number. Pick a number, say 4, and find where it can still go in each box. When a box has only one cell left for it, place it.
  • Start with the fullest rows, columns and boxes. They have the fewest options.

Use pencil notes

When a cell could hold more than one number, switch on Notes and jot down the candidates. As you place numbers elsewhere, cross candidates out. A cell with a single candidate left is solved. Notes are optional on easy puzzles and a real help on hard ones.

Frequently asked questions

What are the boxes in a 6x6 sudoku?

Six boxes of two rows by three columns. Each must contain 1 to 6 once.

Do I need to guess?

No. Every puzzle in Logiclings has one solution you can reach by logic.

What are notes?

Small candidate numbers you write in a cell while you are unsure. Turn them on with the Notes button.

Is a 6x6 sudoku easier than a 9x9?

It is smaller and quicker, but it uses the same logic, so it is a good place to start.
