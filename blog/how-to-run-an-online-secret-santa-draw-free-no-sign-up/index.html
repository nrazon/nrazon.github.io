How to Run an Online Secret Santa Draw (Free, No Sign-Up)

By Nesim Razon, independent mobile developer · 2026-11-16

#Tools and calculators

Secret Santa is the easiest way for a group to exchange gifts: everyone buys for exactly one person and nobody knows who bought what until the day. Drawing names from a hat works for a small group, but it breaks down quickly. This guide shows how to run the draw online, which mistakes to avoid up front and how to hand out the matches privately.

What is a Secret Santa draw?

In a Secret Santa draw, every person in the group picks one name and buys a gift, within an agreed budget, only for that person. The gifts are handed over on a set date, often Christmas or New Year. The giver stays anonymous, and guessing who it is half the fun.

The format keeps things fair: everyone gives one gift and receives one gift, and the spending stays under control. In an office of twenty, buying for everyone is expensive and tiring. With a draw, everybody thinks hard about a single present.

Why the paper-hat method breaks down

The classic method writes names on slips, drops them in a bowl and draws one by one. Even in a small group three problems appear. Someone can draw their own name and the draw has to be repeated. Partners or siblings can draw each other, which spoils the surprise for many groups. And everyone has to be in the same place at the same time, so a remote colleague or someone absent that day cannot join.

Drawing your own name is more likely than most people expect. As a group gets larger, the chance that nobody draws themselves approaches about 37 percent. In most attempts at least one person draws their own name and the draw needs to be redone. With three people the chance is 33 percent: only two of the six possible arrangements are valid. A computer does this elimination in a fraction of a second.

The rules of a good draw

A proper draw follows a few simple rules:

  • Nobody draws themselves.
  • Everyone buys for exactly one person and receives from exactly one person.
  • Unwanted matches (couples, siblings, people who live together) can be blocked.
  • If possible, when A buys for B, B does not buy for A; gifts travel in a loop (A → B → C → … → A).
  • Only the person concerned sees their match.

An honest note on the last rule: whoever runs the draw can see all the matches, because they generate the links. So let someone the group trusts run it. Some groups pick a neutral person who is not taking part.

Step by step: how to run it online

You can use the free Secret Santa tool on this site and finish the draw in a few minutes. There is no sign-up and nothing to install; it works in a phone or desktop browser.

  • Type the participants, one name per line. You need at least 3 and at most 50 people. If the same name is written twice the tool warns you; if two people share a name, add a last-name initial.
  • If needed, fill in the box "Who must not draw each other (optional)" with one pair per line, for example Anna - Mark. The rule works both ways: neither draws the other.
  • Optionally add a draw name, a gift budget, an exchange date and a short note; the name, budget and date go into the message each person receives.
  • Press "Run the draw". The matches are ready.
  • Hand out the matches by passing the phone around or by sending each person their own link.

Keeping couples and siblings apart

This is the most requested feature. When you add a rule the tool never matches that pair, and in a family of three or four you can add as many rules as you need. Too many rules can make the draw impossible, though: in a group of four, if you forbid everyone from drawing everyone, nobody is left to draw. In that case the tool says the draw is impossible with these rules and asks you to remove a few and try again.

The draw first tries to build a single big loop (A → B → C → … → A). When such a loop exists, nobody has a two-way match. If the rules are so tight that no loop can be built, the tool falls back to a general draw. Two people may then buy for each other, but every rule you entered is still respected.

How to hand out the matches in secret

The tool has two ways. The first is "Pass the phone around": everyone taps their own name in turn, sees who they will buy for and taps "Hide" before passing the phone on. It suits groups who are in the same room, such as an office or a family.

The second is "Private link per person": a separate link is created for each participant. You send the link straight to that person, for example on WhatsApp, and whoever opens it sees only their own match. This is the best way for people who are far away or cannot be there on the day. Send links one by one rather than in the group chat, or the whole group will see them.

Where does the data live? Privacy

The draw runs in your browser. The names, rules and matches you enter are not sent to any server, and you do not need an account. In a private link the match is encoded in the part of the address after the # sign, and browsers do not send that part to the server.

One thing needs saying plainly: the encoding in the link is not encryption. Anyone who has a link can see that person's match, and the organizer can see all of them. So send each link only to the right person and do not post screenshots in public places.

Who should run the draw?

A group works best with one organizer: the person who collects the names, asks about exclusions and runs the draw. Because the organizer can see every match, pick someone trustworthy. It is very common for the organizer to take part too, and it usually causes no problems.

It is good practice to have everyone confirm the name list in the group chat. If a misspelled name or a forgotten participant turns up after the draw, the draw has to be redone, and checking first prevents that.

Common mistakes

  • Writing names inconsistently: "Anna" and "Anna K." count as two different people. Write each person the same way every time.
  • Adding too many rules: the more rules, the harder the draw, until it becomes impossible. Only add the pairs you really need.
  • Posting links in the group chat: then everyone sees every link and the secret is gone. Send each link only to the person it belongs to.
  • Drawing too late: finding, ordering and shipping gifts takes time.
  • Not stating the budget: one person spends 20 and another 200, and it feels unfair.

Tips to make it more fun

Write the budget clearly at the start and put it where everyone will see it, so the gifts have similar value. Fix the date and place of the exchange early. You can ask participants for a few hints: a favourite colour, a hobby, or something they would rather not receive.

If someone drops out after the draw, the safest fix is to redo the draw. Removing the person and drawing again changes the matches, but everyone starts fresh. Do the draw early enough to leave time for shopping, but not too early: two weeks before the exchange is usually enough.
