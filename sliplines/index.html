Sliplines

Arrow escape puzzle: slide every arrow out. New daily puzzle, plays offline!

Every arrow wants out. Can you find the right order? Sliplines is a calm, clever arrow puzzle and brain teaser. Each board is packed with winding arrows. Tap an arrow and, if nothing blocks its head all the way to the edge, it slides off the board along its own path. If another arrow is in the way, you lose a heart. Clear the board to escape the level.
